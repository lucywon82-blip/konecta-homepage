## 2. 권한(permission) 설정 조정

문제: 예약 작업이 파일 업로드·페이지 수정 같은 쓰기 작업마다 승인 팝업을 기다리며 멈춰서, 사람이 깨어서 매번 승인해줘야만 끝까지 진행됨.
예약 작업의 취지(사람 없이 자동 실행)에 맞지 않아 권한 모드를 조정함.

진행 순서:
1. 세션 로컬 설정에 자주 쓰는 읽기 전용 MCP 도구 12개를 허용 목록에 추가 (`fewer-permission-prompts` 스킬로 최근 세션들의 실제 호출 빈도를 분석)
2. 그래도 남는 마찰(특히 파일 업로드 curl 요청)은 근본적으로 permission mode 자체를 바꿔야 해결된다는 사용자 판단에 따라, 이 세션에 한해 `defaultMode: bypassPermissions` 적용
3. 예약 작업은 매일 새 임시 폴더에서 실행되기 때문에 세션 한정 설정으로는 소용이 없다는 점을 확인 → 전역 설정(`~/.claude/settings.json`)에도 같은 읽기 전용 도구 12개 등록
4. 사용자가 "매일 아침 루틴은 사람이 깨어있지 않아도 알아서 완료되어야 한다"고 명시적으로 요청 → 전역 설정에도 `defaultMode: bypassPermissions` 적용 (이 컴퓨터의 모든 Claude Code 세션에 영향을 미친다는 점을 사용자에게 고지함)
5. 사용자가 "삭제, 강제 push, 시스템 설정 변경은 그래도 확인받고 실행해"라고 요청 → `permissions.ask` 목록에 삭제(`rm`/`Remove-Item`/`git clean`/`git branch -D`/`git reset --hard`), `git push`(force 여부 무관 전체), 레지스트리·윈도우 서비스 변경, 그리고 이 설정 파일 자체에 대한 재수정을 포함시킴

세부 설정 내용과 근거는 같은 폴더의 `README.md`, 실제 파일은 `settings.json` 참고.
