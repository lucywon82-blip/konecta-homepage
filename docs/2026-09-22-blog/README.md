## 상태

- 노션 "발행" 체크박스를 켜서 Cloudflare Pages 빌드 시 실제 `/blog` 페이지에 반영되도록 함

- SNS: Claude in Chrome으로 `@konecta.2026` 계정에 로그인해 카드뉴스 6장 + 캡션을 실제로 게시함 (https://www.instagram.com/p/DdlsdEmn4BB/). 로그인 자체는 사용자가 직접 함 — Claude는 비밀번호를 입력하지 않음
