매일 아침 Konecta 블로그 글(네이버용 1개 + 홈페이지용 1개)과 카드뉴스(인스타그램용+네이버 첨부용 10장, 스페인어 버전 5장 포함)를 자동으로 만드는 고정 워크플로우입니다. "오늘자 블로그 써줘" 같은 요청이나 이 목적의 일일 자동 실행 트리거에서 항상 이 스킬을 먼저 읽고 그대로 따르세요.

노션 원본: https://app.notion.com/p/3e36f13048af81039f5ad31d9cfdb08b

> **2026-09-22 업데이트 (사용자 지시)**
> - 홈페이지용 글의 "발행" 체크박스는 이제 **항상 자동으로 켠다** (`__YES__`). 더 이상 사람 검토를 기다리는 초안으로 남기지 않는다 — 아래 5번 항목과 "항상 지키는 것"의 관련 문구는 이 업데이트로 대체됨.
> - 발행 체크 후 `konecta-homepage` 저장소에 오늘 카드뉴스(PNG)와 글 요약을 `docs/YYYY-MM-DD-blog/`로 커밋하고 `main`에 push한다 — 이 push가 Cloudflare Pages 재배포를 트리거해 실제 `/blog`에 반영된다 (push 승인은 상시 허용됨, 2026-09-21부).
> - SNS(인스타그램 등) 실제 게시는 아직 자동화 전이다 — 이 저장소에 Meta Graph API 같은 실제 게시 연동이 없어서, daily-instagram-content가 만드는 릴스 대본·카드뉴스는 여전히 초안이며 사용자가 직접 게시해야 한다. 연동이 준비되면 이 문서를 다시 갱신한다.
> - 참고: 2026-09-22 실행 시점에는 실제로 동작 중인 자동화 프롬프트가 이 문서의 1~7번(네이버용 글 포함 전체 구조)과 다르게, 홈페이지용 글 1개만 만드는 더 단순한 흐름으로 되어 있었다(`docs/2026-09-22-blog/README.md` 참고). 두 문서를 다시 일치시키는 정리가 필요할 수 있음.
> - **커버 이미지는 매번 필수** (2026-09-22에 빠뜨려서 `/blog` 목록 카드에 사진이 안 뜨는 실수가 있었음): 노션 페이지를 만든 뒤 반드시 `notion-update-page`의 `cover` 파라미터로 외부(Unsplash) 이미지 URL을 지정한다. `cover`가 없거나 Notion에 업로드한 파일(`type:"file"`)이면 `scripts/build-blog.mjs`가 사진을 렌더링하지 않는다 — 반드시 `type:"external"`인 `https://images.unsplash.com/photo-<id>?w=1600&q=80&auto=format&fit=crop` 형식이어야 한다. 이미지를 고르면 curl로 실제로 받아서(Read로 보고) 글 주제와 실제로 어울리는지 확인한 다음에 지정한다(추측만으로 URL을 넣지 않는다).
> - **인스타그램 계정은 `@konecta.2026`** (2026-09-22부로 변경, 기존 `@konecta.co.kr`/`noriter_beautycenter`는 더 이상 쓰지 않음). 실제 게시가 필요하면 Claude in Chrome으로 이 계정에 로그인된 상태에서 직접 게시할 수 있다(로그인 자체는 사용자가 비밀번호를 입력해야 함 — Claude가 대신 입력하지 않는다).

## 1. 오늘의 주제 찾기
Notion 블로그 콘텐츠 캘린더(collection://b7b82e4e-33ea-41f1-8ffc-19b4265c1a8e, https://app.notion.com/p/4d006da5b45344e49b484e0cf38f3f6c)에서 발행일이 오늘 날짜이고 상태가 "예정"인 주제를 SQL로 찾는다. 없으면 다른 작업 없이 정확히 "오늘 예정된 주제가 없어"라고만 답하고 끝낸다(카드뉴스도 만들지 않음). 여러 개면 하나만 처리.

## 2. 주제 확인 및 키워드
주제 페이지를 notion-fetch로 열어 제목·필라·핵심메시지·톤체크 확인.
- 핵심메시지에 "메인: ... | 보조: ..." 형식이 있으면 그대로 사용, 없으면 blog-writer-general 스킬의 키워드 자동추출 규칙으로 메인 2개/보조 2~3개 직접 판단.
- 글유형은 필라 기준: 창업일기→브랜드스토리형, 브랜드소개→브랜드스토리형, 시장정보→정보형, 남미진출→정보형, 제품소개→구매유도형(홍보성).
- 구매유도형은 사업설명서(https://app.notion.com/p/3cf6f13048af81119108ef2cd0947c22)를 먼저 읽고 브랜드 톤·USP·피해야 할 표현·가격 미정 상태 반영. 미확정 가격/판매 여부를 확정처럼 쓰지 않는다.
- blog-writer-general 스킬 규칙(줄바꿈, 키워드 배치, 글유형별 구조, 금지사항)을 예외 없이 지킨다. 메인 키워드는 반드시 본문에 포함.
- 통계·수치·뉴스 등 사실 확인 필요한 내용은 지어내지 않는다. 확인 안 되면 뺀다. 시장정보 필라는 웹검색으로 확인된 내용만, 출처 불명이면 그 문장은 뺀다.

## 3. 네이버용 글
완성한 글 전체를 그 주제 페이지 본문에 넣는다(notion-update-page, replace_content). 글 전체를 마크다운 코드블록으로 감싸고, 위에 "메인 키워드: OO / OO | 보조 키워드: OO / OO / OO" 요약 한 줄.

### 3-1. 수식 강조 (매일 빠짐없이 적용)
naver-blog-highlight-style 스킬을 읽고 그대로 따른다. 완성한 네이버용 글에서 강조하고 싶은 문장(키워드 포함, 핵심 문장) 2~4개를 고르고, 3번 코드블록 바로 아래에 "▶ 수식 삽입용 (해당 위치의 일반 텍스트를 지우고 수식으로 교체하세요)" 안내 줄과 함께 번호를 붙여 `\color{#ED7B5D}\textsf{\textbf{그 문장}}` 형식으로 정리해 추가한다. 코드블록 안 원래 문장은 그대로 둔다(지우지 않음). 3번 호출 안에 이 목록까지 한 번에 포함해서 넣는다.

## 4. 상태 갱신
그 페이지의 "상태" 속성을 "완료"로 바꾼다(update_properties). 캘린더 상태 옵션: 예정/작성중/완료 세 가지 ("대기"=예정, "작성완료"=완료로 매핑).

## 5. 홈페이지용 글 (유사문서 필터 회피용 두 번째 글)
같은 주제로 두 번째 글 작성. 대상: Notion "블로그 글 목록"(collection://9eb29df1-5e9e-43d7-b1de-72c90a7c635d, 상위: Konecta 홈페이지 블로그, https://app.notion.com/p/4d8805402a85467781d5dd76e9f1a186).
- 네이버용과 주제·핵심메시지·키워드는 같지만 도입부·문장구조·예시·표현을 다르게 써서 문장 단위로 겹치지 않게 한다.
- 홈페이지용이므로 네이버 전용 줄바꿈/키워드 반복 하한 규칙은 적용하지 않는다. 자연스러운 문단 형태, 담백하고 신뢰감 있는 톤. 코드블록·키워드 요약 줄 없음(수식 강조도 적용 안 함).
- 글유형별 구조와 사실확인 규칙은 2번과 동일.
- notion-create-pages로 새 페이지 생성. parent: {"type":"data_source_id","data_source_id":"9eb29df1-5e9e-43d7-b1de-72c90a7c635d"}.
  속성: 제목(네이버용과 다른 표현) / 슬러그(영문 소문자+하이픈) / 요약(1~2문장) / 카테고리(창업일기·남미진출·시장정보→"루틴", 브랜드소개·제품소개→"소식"; 소식/루틴/후기 중 하나만) / 발행일(오늘 날짜) / 발행 체크박스는 항상 "__NO__"(사람이 검토 후 직접 켜도록 초안으로 남김, 자동 체크 금지).
  본문에는 완성된 글만.

## 6. 홈페이지 디자인 미리보기
konecta-blog-article-style 스킬을 반드시 읽고 그대로 따른다.
- 5번 글의 제목·본문·카테고리를 그대로(재창작 없이) 가져와 레이아웃(상단 내비 → 카테고리 배지+제목+날짜 → 본문 → 인용구 카드 1개 → CTA → 푸터)에 맞춰 design 스킬로 Main.dc.html 작성. 핵심 문장 하나를 인용구 카드에.
- Artifact 도구로 발행(contract: "0.1.31", capabilities는 design 스킬 규칙대로).
- 발행 링크를 5번 노션 페이지 맨 위에 "미리보기: <링크>" 한 줄로 추가(insert_content, position start).
- 이 아티팩트는 미리보기일 뿐 실제 Konecta 홈페이지에 자동 반영되지 않는다는 점을 알고, 보고 시 "미리보기"라고 명확히 표현한다.

## 7. 카드뉴스 5장 (인스타그램용 + 네이버 첨부용, 매일 필수)
5번 글의 제목·핵심메시지로 같은 주제의 카드뉴스 5장을 만든다(블로그 글이 있는 날은 카드뉴스도 있는 날).

사진 확보(먼저 한 번만 시도, 실패하면 즉시 아래 방법으로 — 재시도로 시간 끌지 않음): WebSearch로 "site:pexels.com <영어 키워드>"로 상업적 재사용 가능 사진 검색 → WebFetch로 이미지 CDN URL 확인 → Bash curl로 다운로드 시도. (이 클라우드 환경은 임의 외부 사이트 다운로드를 차단할 수 있음 — 실패 시 즉시 아래로.)

사진 없이 만드는 방법(기본값, 카드뉴스를 건너뛰지 않는다): Konecta 브랜드 컬러만 사용(Navy Dark #1D2530, Navy #2B3648, Navy Soft #5B6472, Coral #ED7B5D, Coral Light #FCEEE8, BG Gray #F7F8FA). 1,3,5번 카드 다크 그라데이션 배경+흰 글씨, 2,4번 카드 라이트 그라데이션+네이비 글씨. 우측 하단 겹치는 원 두 개(스트로크만, 코랄). 폰트 'Noto Sans CJK KR'(헤드라인 900, 서브카피 500). 상단: 좌측 "Konecta" 워드마크, 우측 페이지 번호("01 / 05"), 구분선. 하단: 좌측 코랄 바, 우측 "다음 이야기 →"(5번 카드만 "Konecta 브랜드 이야기"). 중앙: eyebrow 배지 + 헤드라인(2줄 이내) + 서브카피(1~2줄).

카드 5장 구성(매번 새로 작성, 사실 필요한 부분은 2번 기준과 동일하게 안 지어냄): 1장(다크) 표지 / 2장(라이트) 배경·맥락 / 3장(다크) 핵심메시지 / 4장(라이트) 뒷받침 이유·디테일 / 5장(다크) 마무리(확인 안 된 팔로워 수·통계 금지, 계정 핸들 필요하면 "@konecta.co.kr"만 사용).

사이즈: 인스타 1080×1350(세로), 네이버 첨부용 1080×1080(정사각) — 두 벌 총 10장. Python+Playwright(headless chromium, PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers 이미 설정, playwright install 하지 않음)로 HTML 작성 후 device_scale_factor=2 스크린샷. 완성 후 Read로 최소 2장(다크1+라이트1) 검수, 문제 있으면 텍스트 줄여 재생성.
파일명: konecta_cardnews_instagram_01~05.png, konecta_cardnews_naver_01~05.png. SendUserFile로 10장 한 번에 전달.

### 7-1. 카드뉴스 노션 자동 첨부
위 5장(인스타 사이즈 기준)과 완전히 동일한 내용을 SVG 5장(1080x1350)으로 다시 그린다.
- 이 클라우드 환경은 api.notion.com으로 PNG 등 바이너리 직접 업로드를 네트워크 정책으로 차단한다. PNG를 그대로 올리려 시도하지 말고 반드시 SVG 텍스트 방식을 쓴다.
- `<svg width="1080" height="1350">`로 배경 그라데이션, 우측하단 겹치는 원, 상단 워드마크+페이지번호+구분선, 중앙 eyebrow 배지+헤드라인(여러 줄은 tspan)+서브카피, 하단 코랄 바+문구를 동일하게 그린다. font-family "'Noto Sans CJK KR','Malgun Gothic','Apple SD Gothic Neo',sans-serif"(임베드 불필요).
- mcp__Notion__notion-create-attachment로 5번 호출: filename "konecta_cardnews_01~05.svg", content_type "image/svg+xml", content 파라미터에 SVG 마크업 전체(source_file_id 아님 — content 방식이라 네트워크 차단 영향 없음). 반환된 markdown_source(`<image src="file-upload://...">`)를 순서대로 기억.
- 5번에서 만든 홈페이지용 노션 페이지 맨 끝에 notion-update-page(insert_content, position end)로 추가. 이미지들 앞에 "카드뉴스" 소제목 한 줄.
- 실패하면 재시도하지 말고 최종 보고에 "카드뉴스 노션 첨부 실패 — 채팅 전달만 완료"만 남기고 넘어간다. 이 단계 실패가 나머지 작업을 막지 않는다.

### 7-2. 카드뉴스 스페인어 버전 (매일 빠짐없이)
타겟이 페루·칠레(스페인어권)이므로 7-1의 카드뉴스 5장을 스페인어로도 반드시 만든다(예외 없음).
- 동일 레이아웃·색상·장식으로 SVG 5장을 새로 그리되 eyebrow·헤드라인·서브카피·하단 문구만 자연스러운 스페인어(직역투 지양)로. 1~4번 카드 하단 "Siguiente historia →", 5번 카드 "Historia de marca Konecta". 워드마크·페이지번호는 번역 안 함.
- 문장은 한국어 카드 문구의 의미를 그대로 옮기되 자연스럽게 재작성. 사실 필요한 내용은 한국어 버전에 있는 것만.
- notion-create-attachment로 filename "konecta_cardnews_01_es~05_es.svg" 업로드, markdown_source를 7-1 카드뉴스 바로 다음에 insert_content(position end)로 추가. 앞에 "Tarjetas de Konecta (Español)" 소제목.
- 실패하면 최종 보고에 "카드뉴스 스페인어 버전 노션 첨부 실패"만 남기고 넘어간다. 나머지 작업을 막지 않는다.
