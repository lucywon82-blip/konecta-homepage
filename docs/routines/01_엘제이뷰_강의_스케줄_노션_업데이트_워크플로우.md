# 엘제이뷰 강의 스케줄 → 노션 업데이트 워크플로우

매일 Lucy(사용자)의 강의 스케줄(LJ VIEW Studio "AI 온라인 마케팅 과정 심화반")을 확인해서 노션 수업 정리 페이지를 최신 상태로 유지하는 고정 워크플로우입니다. "강의 진도 확인해줘", "수업 정리 페이지 업데이트해줘" 같은 요청이나 이 목적의 일일 자동 실행 트리거에서 항상 이 스킬을 먼저 읽고 그대로 따르세요.

노션 원본: https://app.notion.com/p/3e36f13048af81499924eb88a5a32808

## 대상
- 강의 사이트: https://course.ljview.co.kr/ (LJ VIEW Studio, "마케터 엘제이 강의 자료실")
- 업데이트할 노션 페이지: https://app.notion.com/p/3d46f13048af81cca88dc23f2ddff7f4 ("AI 온라인 마케팅 과정 심화반 - 수업 정리")

## 절차
1. mcp__remote-devices__Claude_Browser__* 도구(필요시 ToolSearch로 로드)로 강의 사이트를 엽니다. 막혀 있으면 request_access로 허용 요청.
2. 로그인이 풀려 있으면(우측 상단에 사용자 이름이 안 보이면) 비밀번호를 대신 입력하지 말고 사용자에게 "로그인이 풀려서 이번 확인은 건너뛰었다"고 알리고 종료합니다.
3. 로그인돼 있으면: 전체 진행률(%, N/18일), 18일치 커리큘럼(날짜·요일·카테고리·주제), "강의자료" 섹션 파일 목록/구글드라이브 링크, "메모 보기"의 최신 메모를 확인합니다.
4. notion-fetch로 노션 페이지 현재 내용을 가져와 비교: 진행률 변화 / 새로 완료된 날짜 / 커리큘럼 추가·변경 / 강의자료 신규 파일 / 새 메모.
5. 변경 사항이 있으면 notion-update-page로 갱신: 진행률, 커리큘럼 표 상태(✅완료/⏳예정), 완료된 날짜는 서술형 문단으로 "일자별 학습 내용 정리"에 추가(사이트 항목명 그대로 나열 금지), 강의자료 표에 새 파일 행 추가, 메모는 콜아웃으로 추가. 기존 내용은 삭제하지 않고 추가/갱신만.
6. 변경 없으면 조용히 종료(알릴 필요 없음).
7. 변경 반영했으면 2~3문장으로 무엇이 바뀌었는지 알립니다.
8. 사이트 구조가 크게 바뀌어 정보를 못 찾으면 추측하지 말고 상황을 설명하고 종료합니다.
